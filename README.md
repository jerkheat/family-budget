# 💚 FamilyBudget — общий кошелёк с AI-ассистентом

Сервис совместного бюджета для студентов, семей и друзей:
один бюджет + семейный чат + AI-финансист в одном окне.

## ✨ Возможности
- 👥 Одна группа = один общий бюджет (код приглашения)
- 💬 Чат: фото, голосовые, ответы, закреп, уведомления со звуком
- 💸 Автоматический расчёт долгов + история возвратов
- 📊 Аналитика: категории, динамика по дням и месяцам
- 🤖 AI-ассистент (DeepSeek): советы по реальному бюджету группы
- 🎯 Цели-копилки и лимит месяца с уведомлениями
- 📱 Адаптивная мобильная версия

## 🛠 Стек
- Backend: FastAPI, SQLAlchemy, SQLite
- Frontend: React, Vite, Tailwind, Zustand
- AI: DeepSeek + эвристический фолбэк-аналитик

## 🚀 Запуск
**Backend:**
cd backend && pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000

**Frontend:**
cd frontend && npm install && npm run dev

Открыть: http://localhost:3000
